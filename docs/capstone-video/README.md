# Open-SE capstone video presentation

Open [index.html](index.html) in a browser. The presentation works offline and advances only when you choose.

- **Next / previous:** Right or Left arrow, Space or the on-screen buttons.
- **Full screen:** F or the full-screen button.
- **Speaker notes:** N or the Notes button. Keep notes hidden when recording the slide window.
- **Script:** [speaking-script.md](speaking-script.md).

The slide transitions and diagram accents animate when a slide appears. The slides do not auto-advance. Browser reduced-motion settings disable the animations.
