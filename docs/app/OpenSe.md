## Description:

The team may choose one of the projects below as the preferred product for this round of studio, a decision can be made during/after team formation.

### **Open-ETL**
**Goal:** An open source web-based SAAS that allows organisations to create centralised customised workflow to import, process, visualise and export data.  
**Some requirements include:**
- Data management - all processing should be done within the browser, nothing should be uploaded to the cloud.
- Easy to use UI/UX that allows user with no coding background to easily create understandable workflows that can be easily configured & modified.
- Logging - All actions should be logged.
- Organisation management - User should be able to manage a team.
- Payment systems - An easy, simple to use payment system should allow user to subscribe & upgrade their plan.

### **Open-StoQr**
Goal: An open source web-based SAAS that allows organisations to track inventory management, with integrated QR-code and barcode scanning system that allows for easy stock update.
**Some requirements include:**
- Easy to use UI/UX with high accessibility.
- Simple stock management system.
- High customisation.
- Logging - All actions should be logged.
- Organisation management - User should be able to manage a team.
- Payment systems - An easy, simple to use payment system should allow user to subscribe & upgrade their plan.

Of course, the actual scope of the project would be set by the capabilities of the team, but the idea goal is to have a working prototype by the end of studio.
